请填写你的姓名、所属组别、Linux 用户名与 SSH 公钥。提交后由管理员在 Server C 开通账号。正式链接：https://www.ustquant.hk/ssh-access/

如何生成 SSH 公钥

按你的系统选择步骤。只需把 公钥（.pub 文件内容）粘贴到右侧表单。

1. macOS / Linux / Git Bash

  1. 打开终端，执行：
ssh-keygen -t ed25519 -C "your_name@quantsociety"

提示保存路径时直接回车即可，默认生成：

~/.ssh/id_ed25519 ~/.ssh/id_ed25519.pub
注意：id_ed25519 是私钥，切勿发给任何人；id_ed25519.pub 才是可提交的公钥。

查看公钥并复制整行：

cat ~/.ssh/id_ed25519.pub

输出示例：

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... your_name@quantsociety

2. Windows 用户

建议使用 Git Bash、Windows Terminal 或 WSL，命令与 macOS / Linux 相同：

ssh-keygen -t ed25519 -C "your_name@quantsociety" cat ~/.ssh/id_ed25519.pub

若使用 PuTTY 等图形工具，请导出 OpenSSH 格式公钥，不要上传私钥文件。

提交信息

带 * 为必填项。

仅小写英文字母与数字，必须以字母开头，2–16 位。

规范：qs_{组别代码}_{姓名}，例如 qs_agent_alice。选择组别并填写拼音后会自动生成，可手动微调。

粘贴 cat ~/.ssh/id_ed25519.pub 输出的整行内容。
