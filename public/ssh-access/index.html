如何生成 SSH 公钥

按你的系统选择下方步骤。生成公钥后，将 .pub 文件的整行内容粘贴到右侧表单。

1. macOS / Linux / Git Bash

打开终端，运行下面命令。引号里的 zhangsan 换成右侧 Linux 用户名：

ssh-keygen -t ed25519 -C "zhangsan"

保存路径一路回车即可。然后复制公钥整行到右侧表单：

cat ~/.ssh/id_ed25519.pub
只提交 .pub 公钥，私钥 id_ed25519 切勿发给任何人。

2. Windows 用户

用 Git Bash / Windows Terminal / WSL，命令同上。

PuTTY 用户请导出 OpenSSH 格式公钥，不要上传私钥。

提交信息

带 * 为必填项。

小写字母开头；可用全拼（zhangsan）或英文名.lastname（alice.wang）。

一般为姓名全拼（如 zhangsan）或英文名.lastname（如 alice.wang），须符合 Linux 账号规范；填写拼音/英文名后自动生成，可手动微调。

粘贴 cat ~/.ssh/id_ed25519.pub 输出的整行内容。
